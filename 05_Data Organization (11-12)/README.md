# Section 5: Data Organization

This section focuses on organizing and managing complex data. You will learn how to create custom data structures and work with files.

## Lessons

1. Structures
2. Creating Custom Data Types
3. Structure Arrays
4. File Streams
5. Reading Files
6. Writing Files
7. Advanced File Operations
8. Formatted Output

## Learning Objectives

After completing this section, you will be able to:

- Create custom data types using structures.
- Organize related data together.
- Store collections of structured data.
- Read data from files.
- Write data to files.
- Manage persistent program data.

## Competency Alignment

This section supports Competency 6 and Competency 7:

- Structures and custom data types introduce structured data concepts.
- File lessons cover reading and writing sequential files.
- The new formatted output lesson helps students produce neat, readable output.
