# Section 3: Data Collections

This section covers how to store and manage groups of data. You will learn how to work with arrays, vectors, searching, and sorting algorithms.

## Lessons

1. Arrays
2. Array Manipulation
3. Multi-Dimensional Arrays
4. Vectors
5. Vector Methods
6. Searching Algorithms
7. Sorting Algorithms

## Learning Objectives

After completing this section, you will be able to:

- Store multiple values using arrays.
- Access and modify elements in collections.
- Work with two-dimensional arrays.
- Understand the advantages of vectors over arrays.
- Use built-in vector methods.
- Search through collections of data.
- Sort data using common algorithms.

## Competency Alignment

This section supports Competency 6:

- Arrays and multi-dimensional arrays are introduced here.
- Searching and sorting activities help students evaluate and manipulate collections.
- These lessons build the foundation for structured data and later data organization topics.
