# Section 6: Object-Oriented Programming

This section introduces object-oriented programming (OOP), one of the most important programming concepts in C++. You will learn how to create reusable and organized code using classes.

## Lessons

1. Classes and Objects
2. Constructors and Destructors
3. Encapsulation
4. Member Functions
5. Inheritance
6. Polymorphism
7. Virtual Functions

## Learning Objectives

After completing this section, you will be able to:

- Create classes and objects.
- Define attributes and behaviors for objects.
- Use constructors and destructors.
- Protect data using encapsulation.
- Reuse code through inheritance.
- Understand polymorphism.
- Use virtual functions for dynamic behavior.

## Competency Alignment

This section supports Competency 6:

- Classes and objects introduce object-oriented design.
- Encapsulation and member functions show how data can be protected and managed safely.
- Inheritance and polymorphism explain how behavior can be shared and customized.
