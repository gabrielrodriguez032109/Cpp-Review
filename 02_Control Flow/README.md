# Section 2: Control Flow

This section introduces how programs make decisions and repeat tasks. You will learn how to control the flow of a C++ program using conditional statements and loops.

## Lessons

1. Boolean Values
2. Relational Operators
3. If Statements
4. If/Else Statements
5. Switch Statements
6. While Loops
7. For Loops
8. Do-While Loops
9. Logical Operators
10. Nested Conditionals

## Learning Objectives

After completing this section, you will be able to:

- Use boolean values to represent true and false conditions.
- Compare values using relational operators.
- Create programs that make decisions using conditional statements.
- Use switch statements for multiple choices.
- Repeat code using different types of loops.
- Understand how program execution flows from one statement to another.

## Competency Alignment

This section directly supports Competency 3 and Competency 4:

- Competency 3: The lessons cover if, else, logical operators, comparison operators, switch/case/break, and nested conditionals.
- Competency 4: The lessons cover while, do-while, for, and nested loops.

## Review Practice

- Write a program that uses both logical and comparison operators in one condition.
- Create a nested conditional statement to decide between several outcomes.
- Trace a loop by hand and predict the output before running it.
