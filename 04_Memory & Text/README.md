# Section 4: Memory & Text

This section introduces memory management and text handling in C++. You will learn how data is stored in memory and how to work with strings.

## Lessons

1. Memory Addresses
2. Pointers
3. Pointer Operations
4. Dynamic Memory Allocation
5. C-Strings
6. The string Class
7. String Manipulation

## Learning Objectives

After completing this section, you will be able to:

- Understand how memory addresses work.
- Create and use pointers.
- Access data indirectly through pointers.
- Allocate and manage memory dynamically.
- Work with C-style strings.
- Use the C++ string class.
- Manipulate text data efficiently.
